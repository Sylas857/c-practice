# c-practice

我的第一个 C 语言练习仓库（嵌入式方向）。

## 文件

- `hello.c` —— 第一个程序
- `switch-demo.c` —— 用 switch 写的小计算器

## 编译运行

```bash
gcc hello.c -o hello
./hello.exe

gcc switch-demo.c -o switch-demo
./switch-demo.exe
```

## 我学到的 git 命令

```bash
git init            # 把当前文件夹变成 git 仓库
git status          # 看哪些文件改动了
git add .           # 把改动放进暂存区
git commit -m "说明" # 提交一次快照
git push            # 推到 GitHub
git log             # 看历史提交
```
